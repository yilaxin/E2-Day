# E²-Day Teacher 1.0.5 · 更完整的学生资料与学习特点选择

编辑学生时，可在“基本资料”填写就读学校和授课地点；“学习特点”提供可选的基础水平、学习节奏和辅导重点，减少重复打字。原来的自由备注继续保留。

- **基础水平，单选**：需巩固、中等、良好、优秀。
- **学习节奏，单选**：较慢 · 需要多练、适中 · 稳步推进、较快 · 理解较快。
- **辅导重点，多选**：基础巩固、查漏补缺、同步提高、拔高拓展、考试冲刺、习惯培养。

所有选项都可暂不选择或以后调整。学校、地点与标签显示在学生列表及档案卡片，支持搜索。只有点击底部“保存”才生效；原有文字、课程历史和收入计算不受影响，“复制给家长”不会附带这些内部学生资料。

- [高通等 ARM 电脑：ARM64 程序包](https://github.com/yilaxin/E2-Day/releases/download/tutor-v1.0.5/E2-Day-Tutor-v1.0.5-win-arm64.zip)

旧版学生资料和旧家教版备份可直接读取，新字段默认为空；新增字段随本机保存、自动备份和导出备份一起保留。更新前导出备份并关闭旧版，完整解压新包，再更新桌面快捷方式。含新字段的记录请继续用 1.0.5 或更新版本编辑、恢复，旧版可能丢弃不认识的字段。

程序仍为 E2Day.Tutor.exe，桌面名称 **E²-Day Teacher**，使用原版 logo，独立于日常版。包内附带“先读我.txt”和更新教程。程序目前没有数字签名，首次启动系统信誉提示的处理步骤见教程。

已通过 23 项家教版核心测试与 68 项日常版核心回归测试；ARM64 / x64 正式程序分别通过 150 项 WPF 检查。验证覆盖旧数据库及旧备份、新资料重启与备份恢复、选项修改和清空、资料搜索、家长反馈范围、两个实际发布程序的 WPF 操作、完整解压后的首次账号窗口、架构、版本、依赖与公开下载 SHA-256。x64 程序在 Windows ARM64 的系统兼容环境中验证。
