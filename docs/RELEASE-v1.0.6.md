# E²-Day 1.0.6 · 长期任务

发布日期：2026-10-12。

这次增加长期任务，适合学习计划、持续项目和每天需要推进的事情。在“添加任务”中勾选“长期任务 · 每天出现，手动结束”，设置开始日期即可；普通任务也可以在编辑窗口转换。

- “今日完成”只完成今天，第二天继续出现。
- “结束”停止后续每天出现，历史完成记录保留；需要继续时可以重新开始。
- 昨天未完成的每日任务保留在历史中，今天只显示今天这一项。
- 重要标记和图文备注延续到未来，日历与备份保留每日安排、完成与结束状态。

下载适合系统类型的 ZIP，完整解压后运行 `DailyRecord.exe`。程序包自带运行依赖。

- [Windows x64（Intel / AMD）](https://github.com/yilaxin/E2-Day/releases/download/v1.0.6/E2-Day-v1.0.6-win-x64.zip)
- [Windows ARM64（Snapdragon 等）](https://github.com/yilaxin/E2-Day/releases/download/v1.0.6/E2-Day-v1.0.6-win-arm64.zip)
- [SHA-256 校验文件](https://github.com/yilaxin/E2-Day/releases/download/v1.0.6/SHA256SUMS.txt)

旧版数据与备份继续兼容；包含长期任务的数据或备份需要 1.0.6 或更新版本。更新前关闭已有程序，再完整解压新包。

验证：39 项核心测试及 ARM64、x64 发布程序的 WPF 回归。长期任务覆盖同日去重、跨天、今日完成、结束、重新开始、普通任务转换、历史保留、图文备份、未来开始与闰日；程序版本、PE 架构、必要文件和 SHA-256 均检查。
