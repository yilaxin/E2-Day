# E²-Day Teacher 1.0.4 · 同步日常版界面与顺滑滚动

家教版同步日常版近期的 UI 优化：粉紫渐变背景与柔和光晕、半透明玻璃卡片、悬浮圆角侧边栏、圆角输入框和下拉选项。今日授课、授课日历、学生档案、收入统计、教学记录及设置页使用一致的配色与顺滑滚轮操作，连续滚动合并、反向及时响应，切换页面立即停止旧动画，遵循 Windows 的动画设置。

保留醒目的“在这一天添加课程”按钮、原版 E²-Day logo 与 **E²-Day Teacher** 桌面名称。程序仍为 **E2Day.Tutor.exe**，账号、学生、课程、反馈、收入计算、数据目录及备份格式沿用家教版规则。日常版独立运行。

- [普通 Intel / AMD 电脑：x64 程序包](https://github.com/yilaxin/E2-Day/releases/download/tutor-v1.0.4/E2-Day-Tutor-v1.0.4-win-x64.zip)
- [高通等 ARM 电脑：ARM64 程序包](https://github.com/yilaxin/E2-Day/releases/download/tutor-v1.0.4/E2-Day-Tutor-v1.0.4-win-arm64.zip)
- [更新后的七页 PDF 教程](https://github.com/yilaxin/E2-Day/releases/download/tutor-v1.0.4/E2-Day-Tutor-Guide-v1.0.4.pdf)

下载后完整解压，再双击 E2Day.Tutor.exe。两个包内均附带“先读我.txt”和“安装与使用教程.pdf”，教程截图已更新；首次系统信誉提醒的处理方式见教程。程序目前没有数字签名。

已通过 17 项家教版核心规则测试；ARM64 与 x64 实际发布程序分别通过 139 项 WPF 检查，覆盖、主题资源、指定日期按钮、滚轮连续输入与反向、切页停止、完整解压后的首次账号窗口、程序版本、架构和必要文件。公开后重新下载两个 ZIP 与 PDF 核对 SHA-256。x64 程序在 Windows ARM64 的系统兼容环境验证。

更新前导出备份并关闭旧版，完整解压新版后更新桌面快捷方式；原有本机记录继续使用。历史发布与原有版权许可保留。
