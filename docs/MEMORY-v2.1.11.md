## 资源生命周期验证

- 最近一个全年和一个月历布局短时保留，约 45 秒未访问后在空闲优先级清理；快速返回仍复用原控件与布局。
- 清理遇到滚动／鼠标捕获时延后，交互结束继续。活动视图不会释放；其他页面刷新不延长旧视图期限。
- 1000／1400 宽真实窗口验证到期后旧视图弱引用可回收、重建读取最新安排、旧输入引用不连带保留页面布局、任务状态和修订号不因回收改变。
- 退出时停止计时器并解除回调，移除年／月视图、旧页面内容、按钮内容和图片来源。保留草稿、筛选、原图、备注、长期任务、热力图范围及图片分享。
- 正式 ARM64／x64 程序执行原连续滚动、反向、边界、日期弹窗、下拉菜单、日历缓存、数据修改和启动回归。x64 在 ARM64 主机兼容环境运行，不替换系统剪贴板。

## 诊断取舍与复现

另做的软件绘制和静态背景实验在本机可降低部分绘图占用，但连续滚动回调间隔变差，因此未作为正常运行方式启用；原硬件加速与原背景继续使用。正常运行没有低内存模式开关，也不改写系统图形设置。

构建对应 Release 后运行 `DailyRecord.exe --data-dir <新隔离目录> --memory-test <报告目录>`。必须显式指定数据目录，程序会在其中另建随机子目录。诊断还记录绘制模式、结构与滚动采样；软件对照参数仅在隔离内存诊断中生效。公开源码不含个人数据库、真实图片、日志或构建缓存。
