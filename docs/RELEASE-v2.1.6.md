# E²-Day 2.1.6 · 主要页面统一平滑滚动

今日清单、全年总览、放大月历和历史记录，现已使用与数据概览相同的平滑滚动效果，保持粉紫玻璃风格。

- 共用短缓动、连续输入合并、细小增量与即时反向处理，沿用 Windows 滚动和动画设置。
- 全年与月历保留独立滚动区域和控件缓存，滚动不重建日历或任务行。
- 切换页面／月份、刷新、完成／撤销、历史搜索和日期筛选会停止旧动画，不继续拉动页面位置。
- 历史日期弹窗滚轮与背景隔离，正常日期选择、快速输入草稿和搜索继续可用。
- 数据概览已有图表、选择菜单、图片分享和原滚轮修复继续保留；设置页与独立编辑窗口保持原行为。
