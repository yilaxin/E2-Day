E²-Day 家教版 1.0.5：先看这里

1. 请完整解压 ZIP，再打开 E2Day.Tutor.exe。
   exe 旁边的 DLL、Data 和 images 都是程序的一部分，请保留。
   不要在压缩包里直接运行，也不要只复制一个 exe 到桌面。

2. 第一次使用前，请打开同目录的《安装与使用教程.pdf》。
   PDF 包含版本选择、Windows 安全提示、账号、录课、反馈、统计与备份步骤。

3. 普通 Intel / AMD 电脑用 win-x64；高通等 ARM 电脑用 win-arm64。
   Windows“设置 → 系统 → 系统信息/关于 → 系统类型”可以查看。

4. 本版没有数字签名。若出现“Windows 已保护你的电脑”，先核对下载来源。
   只有确认来自作者正式发布、愿意信任来源时，才考虑“更多信息 → 仍要运行”。
   若没有这个选项，或出现具体病毒/恶意软件提示，请联系作者或设备管理员。
   无需关闭杀毒软件或系统安全功能。

5. 创建本机账号并保存恢复码，然后添加第一位学生和第一节课程。
   不需要 GitHub 账号，不需要另装 .NET，也没有云端同步。
