# E²-Day 2.1.3 · 数据概览分享图片

数据概览右上角新增“复制为图片”：选择近 7 天、近 30 天、本月或今年，一键复制统计和图表，在聊天窗口按 Ctrl+V 分享。

- 分享统计数字、完成趋势、范围内完成热力图、当前积压和当前选中长期任务的打卡。
- 明确起止日期；热力图与打卡对齐顶部选定区间，独立翻阅的年份／月份不影响图片。积压单独标注截至今天，打卡显示本期完成与区间最长连续。
- 保留粉紫玻璃风格，独立生成完整图片，适配窄窗口、空数据、跨年和闰日；不裁掉底部图表。
- 同时提供原生位图与 PNG，支持剪贴板占用重试和成功反馈，等待复制时切换范围不会混合两份图片。
- 图片含所选长期任务名称，其他任务仅汇总数量；不包含任务清单、备注、备注图片、账号名或本机路径。复制不改写本机记录、不自动向外发送。
