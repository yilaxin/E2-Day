# E²-Day 2.1.0 · 鸿蒙原生应用与文件交换

发布日期：2026-10-15

新增鸿蒙原生版 **0.1.1**：ArkTS / ArkUI 界面、本机账号和 SQLite 记录，独立离线新增、编辑、完成和撤销任务，保留日期、重要标记、备注图片及月历。手机与电脑通过 E2DayExchange v1 JSON 文件预览合并，不提供自动同步或云账号。

原生版已在华为 Pura 70 / HarmonyOS 6.1 使用本人开发者调试签名安装。用户确认账号创建、断网关闭重开、修改后再次重开保留，以及与电脑双向文件往返后的标题、图片和完成状态正确。0.1.1 修复卡片显示旧状态、操作时列表跳动和整页变灰，避免保存时重复读取全部图片；完成／撤销、点击流畅度和桌面名称“E²-Day”均由用户复查通过。

**鸿蒙公开附件为未签名构建，不能直接点 HAP 安装。** 下载者需使用自己的华为开发者账号和设备签名，见[鸿蒙原生版说明](https://github.com/yilaxin/E2-Day/blob/v2.1.0/docs/HARMONY-NATIVE.md)。绑定个人手机的调试包、证书、profile、私钥及口令配置不会公开。原生工程最低与目标 API 20，使用官方 SDK 26 编译；其他机型未逐一真机验证。手机编辑器新建普通任务，导入电脑重复事件后保留原规则。

Windows 提供 **2.1.0 ARM64 / x64** 自包含免安装程序包，设置页版本从程序集读取。Windows 2.0 和现有网页手机版仍兼容相同交换格式；原生版独立编号 0.1.1。原网页入口及历史下载保留，迁移前从旧入口导出交换文件，导入原生版并核对后再处理旧记录。

验证包括核心 60 项、手机规则／文件交换／离线回归、原生领域／SQLite 适配／任务卡片回归、实际 C# 含图文件往返、官方鸿蒙编译及以上真机检查。Windows 双架构发布程序完成实际 WPF 验证，x64 在 Windows ARM64 兼容环境运行；版本、PE 架构、必要文件、隐私排除和 SHA-256 检查通过。

使用前请导出旧版备份。手机调试签名有有效期和设备范围，续签与更新应保持包名及兼容签名、覆盖安装，避免先卸载导致本机记录丢失。原生数据库及交换文件未加密，请自行保管备份；恢复码仅恢复本机账号访问，不会重建删除的记录。本次未购买付费服务，保留项目原有版权许可。
