# E²-Day 2.0.0 · 独立手机应用与文件交换

发布日期：2026-10-14

手机独立添加并保存任务，电脑和手机通过手动交换文件带入记录。导入先预览，双方独有任务保留，相同记录去重，同一记录有差异时选择版本。

新增本机账号、密码和离线恢复码。每台设备有自己的账号，交换文件包含任务、事件、历史与图片，不包含账号凭据。电脑版首次创建账号前备份旧记录，再迁移到第一个账号。

手机入口采用公开 HTTPS 静态页面，首次联网安装后添加到桌面，随后离线使用。局域网同步、配对和本地 CA 证书配置已停用；电脑不运行手机连接服务。

导入前保留本机副本；校验、图片缺失、存储失败或预览过期时保留现有记录。手机资源更新不阻塞离线首屏。

Windows 提供 ARM64、x64 自包含免安装压缩包。完整解压后运行 DailyRecord.exe。保留历史版本和版权许可，不含个人数据库、备份、日志或凭据。

验证：核心 60 项、手机规则/文件交换/离线回归及 ARM64、x64 自包含程序 WPF 操作通过。版本、架构、必要文件、隐私排除及 SHA-256 检查通过。公开 HTTPS 页面与离线资源已验证，浏览器实际导出文件在电脑读入并再次导出后保留 3 条任务、2 张图片。华为 Pura 70 已由用户确认桌面打开、断网修改重开、手机与电脑双向文件导入导出、图片及完成状态正确。iPhone 未真机验证。

手机安装：[E²-Day 独立手机应用](https://yilaxin.github.io/E2-Day/mobile/)。电脑与手机使用各自本机账号，记录不会自动上传。请定期另存交换文件备份；清理手机站点数据会删除手机本机记录。

更新前请导出旧版备份。电脑版旧记录先备份再迁移到第一个账号，已有候选版账号继续保留。完整解压对应架构包后运行 DailyRecord.exe。交换文件请在两端使用 2.0 或更新版本，旧版电脑仍可用迁移前的旧格式备份。
