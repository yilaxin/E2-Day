# E²-Day 2.1.10 · 大窗口中的从容开场

启动时先打开正常大小的主窗口，在窗口中播放约 3.2 秒的“向着朝阳出发”，随后直接显示登录页或今日清单。三个阶段共用同一窗口，消除小窗口切换到大窗口的不协调感。

- 天空、道路、朝阳和 E² 的展开统一放慢，完整开场由约 2.2 秒延长到约 3.2 秒，默认静音。
- 从第一帧起点击任意位置立即跳过；触屏和 Esc、Enter、空格同样支持。跳过输入由开场接收，不触发后面的按钮。
- 动画期间改变窗口大小或最大化后，进入应用时保留；账号在后台读取，读取尚未完成时显示静态品牌画面。
- 系统减少动画时仍使用约 0.2 秒静态画面。既有账号、记录、图片、备份与文件交换继续兼容。家教版与手机端保持原版本。
