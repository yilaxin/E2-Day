# E²-Day 2.1.7 · 日常版内存优化

减少备注图片和玻璃卡片的内存占用，保持粉紫玻璃风格、统一平滑滚动和现有操作方式。

- 今日／历史列表共用小缩略图，点击时才读取完整原图；不再让每个缩略图长期保留原图 PNG。
- 当前窗口的缩略图缓存最多 64 项，像素预算 4 MiB；长边最多 200 像素、不放大小图，数据变更后失效，关闭时清空。
- 卡片采用轻量矢量柔影，减少整卡阴影渲染缓冲；保留圆角、半透明卡片、背景和布局。
- 离开概览后释放旧选择器引用，保留日历控件缓存。原图、放大、编辑、备份、账号、统计和图片分享继续兼容。

同一隔离样例中，普通今日页私有内存约 424 → 248 MiB，含图历史页约 886 → 429 MiB，连续切页过程峰值约 1055 → 825 MiB。结果随数据和运行环境变化；测量方法及全部阶段见 [内存对照](https://github.com/yilaxin/E2-Day/blob/v2.1.7/docs/MEMORY-v2.1.7.md)。诊断用显式 GC 仅用于对照，正常 App 不强制 GC 或清空工作集。
