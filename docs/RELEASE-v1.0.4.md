# E²-Day 1.0.4 · 探索每一天

E²-Day 首次公开发布：一款中文 Windows 桌面任务与日历 App，将全年安排、今日清单、完成历史与本机备份放在一起。

## 选择下载包

| 电脑架构 | 文件 |
| --- | --- |
| Intel / AMD 的 64 位 Windows 电脑 | `E2-Day-v1.0.4-win-x64.zip` |
| Windows ARM64 电脑，例如部分 Snapdragon 设备 | `E2-Day-v1.0.4-win-arm64.zip` |
| 下载完整性校验 | `SHA256SUMS.txt` |

完整解压，双击 `DailyRecord.exe` 即可运行，无需另装 .NET 运行时。保留 EXE 旁边的所有依赖与 `Data` 文件夹。首次打开为个人空白清单。

## 功能

- 今日清单：快速添加、重要星标、完成/撤销、编辑改期、逾期延续、取消恢复。
- 全年与月历：每日任务摘要、农历、节日和中国放假调休，附带 2024–2026 年数据。
- 事件安排：一次性或每周、每月、每年公历、每年农历重复，修改单次或这次及以后。
- 提前提醒：三档事件默认提前 0、3、7 天，可在设置中调整。
- 历史：按实际完成日期回看，跨日期搜索标题、备注与历史操作。
- 备份：自动保存、运行当天备份、保留最近 30 份，支持导出与校验后恢复。
- 分享图：一键复制今日待办和今日完成，支持完整长图。
- AI 资讯：公开 RSS 标题、简介与原文链接，中文优先，最多 5 条。
- 天空蓝、米白与朝阳金的统一界面。

## 使用说明

[项目主页与功能截图](https://github.com/yilaxin/E2-Day) · [详细使用说明](https://github.com/yilaxin/E2-Day/blob/main/使用说明.md)

个人记录位于 `%LOCALAPPDATA%\DailyRecord`，任务与日历可离线使用，没有云同步或加密存储。提醒显示在 App 内，关闭窗口即退出，不提供后台系统通知。更新前建议导出备份。
