# E²-Day 2.1.8 · 让热力图适合你的完成量

每天完成超过 7 项时，可以自行调整颜色范围，区分不同的完成量。保持现有粉紫玻璃风格及平滑滚动。

- 在“数据概览 → 完成热力图 → 颜色范围”设置前三档的数量上限，0 项始终独立留白。
- 推荐高完成量预设 5 / 10 / 20，对应 1–5、6–10、11–20、21+ 项；也可自行填写其他严格递增的整数。
- 实时预览图例，保存后生效；支持取消、恢复默认，按账号持久保存并随备份保留。
- 页面全年热力图与所选区间分享图片同步生效，文字对比随色阶调整。完成记录、总数和长期任务打卡口径保持原规则。
