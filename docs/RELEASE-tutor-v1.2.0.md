# E²-Day Teacher 1.2.0 · 同步原版近期改进

将日常版近期适合家教工作的改进同步到 Teacher，保留独立账号、教学记录和原版 logo。

- **同窗口开场**：约 3.2 秒品牌动画，点击、触屏或 Esc／Enter／空格立即跳过；减少动态效果、正常大小窗口、内嵌登录与尺寸／最大化保留。
- **按授课小时设置热力色阶**：预览／取消／保存，默认 1／2／4 小时，另有 2／4／8 预设，支持 0.25–24 小时内以 0.25 小时递增的有效上限，设置按账号保存并随备份保留。
- **匿名教学概览分享图**：按已应用的日期与学生范围完整排版，使用当前色阶；只包含汇总和匿名分布，不包含真实姓名、学校、地点、反馈文字、图片、时薪、收入、账号名或路径。提供位图与 PNG，支持剪贴板重试和关闭取消。
- **图片与页面资源优化**：最多 64 张、4 MiB 像素缩略图缓存，长边最多 200 像素，点击按需读取原图；轻量玻璃柔影，静态资源冻结，拆离旧页面并清理关闭后的资源；切页保留备课待办草稿。

兼容原有学生、课程、图文反馈、示例体验和旧备份。家教版没有隐藏日历控件缓存，因此采用切页释放旧内容；不强制 GC、不清空工作集，也不承诺固定的总进程内存下降。

新用户：完整解压程序包后运行 E2Day.Tutor.exe。已有用户：导出备份、关闭旧版，再完整解压并使用新版；本机账号与记录继续沿用。程序未签名，首次信誉提示处理方式见教程。
