# E²-Day 2.1.13 · 五色任务分类

给任务主动分类，集中查看某个时段准备完成的几件事。

- 蓝、紫、青、粉、灰五色可按账号改名，支持未分类、单项菜单、编辑窗口和批量勾选着色。分类与金色重要星标独立，保留粉紫玻璃界面、平滑滚动与完成淡化。
- 今日清单上方按色筛选，显示当前分类与可见未完成数量；提前提醒及已查看提醒仍计入，完成后数量减少、记录继续显示。切换分类或离开今日页清空批量选择。
- 选择分类后“复制为图片”，生成带分类名称的清单，包含当前分类所有可见未完成及今日完成；备注与备注图片不进入分享。全部范围沿用原分享规则。
- 重复事件和长期任务默认继承分类；可以仅改这一次，或修改后续未完成安排，同时保留其他单次分类。类型互转、图片、状态及历史保留；备份包含分类名称与历史颜色。
