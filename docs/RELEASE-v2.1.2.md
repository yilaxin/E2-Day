# E²-Day 2.1.2 · 数据概览

新增独立“数据概览”页面，用粉紫玻璃卡片展示完成热力图、完成趋势、当前积压和长期任务打卡。

## 本版功能

- 近 7 天、近 30 天、本月和今年四种范围，顶部展示本期完成、其中重要、当前逾期与有完成记录的天数。
- 趋势按日／月汇总，全年热力图支持翻年、闰日和返回今年；点击可查看对应完成事项。
- 积压分为今日到期、逾期 1–3 天、4–7 天和超过 7 天，点击可直接处理，完成、撤销或改期后更新图表。
- 长期任务支持选任务、翻月份和返回本月，显示本月完成、当前及最长连续天数；今天可打卡，已完成可回看与撤销，已结束任务保留历史。

完成趋势与热力图按实际完成日计算，长期打卡按原安排日记一次。看过、取消、结束和已撤销记录不增加完成数；未来提醒、历史长期实例不累积为积压。当前积压不受顶部时间范围影响，热力图年份和打卡月份单独切换。

图表只读取当前账号已有记录，不自动生成历史任务，不变更数据格式，也不向网络发送个人统计。家教版和手机端保留原有入口与界面；未发布的鸿蒙 0.2.0 改动不包含在本版。
