# E²-Day 1.0.5 · 备注图片

这次更新让任务与日历事件的备注同时保存文字和图片，适合附上参考截图、资料照片或需要回看的内容。

## 新功能与使用方法

1. 添加任务、安排事件，或点击任务的“⋯ → 编辑 / 改期”。
2. 在文字备注下点击“上传图片”选择多张图片，或先复制截图，再点击“粘贴图片”。
3. 点击“保存”生效。编辑时点“移除”可删除当前草稿中的图片；取消编辑保留原备注。
4. 在任务卡片、日期详情或历史记录中点击缩略图打开大图，可使用缩放滑块或“适应窗口”查看。

每则备注最多 **8 张图片**，单张原图不超过 **20 MB**。支持 PNG/JPG/BMP/GIF/TIFF，GIF/TIFF 使用第一帧，大图自动缩小至最长边 2048 像素并保存为 PNG。

图片保存在本机数据库，删除原文件后仍可查看，不会上送网络。完成、查看和取消时保存当时的图片快照，之后修改当前备注不覆盖已有历史图片。重复事件按“仅这一次”或“这一次及以后”应用修改。

## 下载

| 电脑架构 | 文件 |
| --- | --- |
| Intel / AMD 的 64 位 Windows 电脑 | `E2-Day-v1.0.5-win-x64.zip` |
| Windows ARM64 电脑 | `E2-Day-v1.0.5-win-arm64.zip` |
| 完整性校验 | `SHA256SUMS.txt` |

完整解压后运行 `DailyRecord.exe`，保留所有依赖与 `Data` 文件夹，无需另外安装 .NET。两个包均未做数字签名。

## 更新与备份兼容

更新前先在旧版 App 中导出备份，再关闭程序并完整解压新包。个人记录继续从 `%LOCALAPPDATA%\DailyRecord` 读取。

新版本的自动、手动及恢复前备份都包含备注图片，兼容读取旧版无图备份。新格式备份需使用 **1.0.5 或更新版本** 恢复；新版本保存后的数据库也已升级，请不要直接用 1.0.4 打开升级后的数据。若需回到旧版，应使用更新前导出的旧版备份。
