# 独立手机版本验收清单

当前为 2.0.0 候选版。用户设备为华为 Pura 70，版本信息由用户提供为 6.25.0.720，未据此推断系统大版本。旧局域网版本的连接验收不代替这份清单。

- [ ] 正式 HTTPS 页面打开，无本地证书或电脑配置要求。
- [ ] 手机创建自己的账号和恢复码，添加任务与备注图片。
- [ ] 提示离线入口准备好后，添加桌面，从新图标打开并看到同一记录。
- [ ] 手机断网、关闭电脑、从最近任务划走后重开，原记录可见；离线新增/编辑/完成后重开保留。
- [ ] 电脑导出含图交换文件，手机选择文件、预览并合并，任务与图片可见。
- [ ] 手机导出后文件确实保存到手机；传到电脑可预览并合并，图片与完成状态一致。
- [ ] 两端分别添加不同任务，交换后保留双方任务；重复导入不新增重复项。
- [ ] 同一任务分别修改，导入显示双方版本，选择后得到所选内容；取消预览不改变记录。
- [ ] 手机查看导入前副本能回退，电脑导入前备份可恢复。

本机验证：核心 60 项通过，手机/电脑文件协议和合并样本一致，图片校验、存储失败与账号切换拒绝覆盖通过，离线首屏回归通过，WPF 预览操作通过。浏览器仅使用隔离示例。

iPhone 尚无真机验证。不得把普通浏览器测试写成所有手机平台已验收。
