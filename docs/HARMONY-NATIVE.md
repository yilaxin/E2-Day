# E²-Day 鸿蒙原生版

这是独立的 ArkTS / ArkUI Stage 工程，源码在 `src/DailyRecord.Harmony`。它使用鸿蒙原生界面、关系型数据库、密码算法和系统文件选择器，不依赖网页容器。当前原生版本为 **0.1.1**，桌面名称为 **E²-Day**，与 Windows 2.0 及更新版本交换文件。

**2026-10-15 状态：官方 SDK 26.0.0.105 编译、本人开发者调试签名及 Pura 70 / HarmonyOS 6.1 安装运行已通过。用户已确认创建账号、断网重开和修改后重开保留，以及与电脑双向交换后的标题、图片和完成状态正确。** 随后的 0.1.1 修复任务卡片状态刷新、操作时列表跳动，去掉桌面名称中的“原生版”；该修复已编译、覆盖安装并启动，用户复查完成、撤销、点击流畅度和桌面名称均正确。

公开附件为**未签名 HAP**及说明，下载者须用自己的开发者账号为自己的设备签名，不能直接点 HAP 安装。本人手机上使用的设备绑定调试包、证书、profile、私钥及口令配置仅保留本机。原生版和 Windows 分别编号；首次原生源码随 E²-Day 2.1.0 发布，不覆盖历史 2.0.0。

## 范围与费用

- 供本人使用，手机独立添加、修改、完成、撤销、取消和恢复任务，支持日期、重要标记与备注图片。
- 本机账号、密码及离线恢复码；各账号记录独立，默认记住已登录账号，可手动锁定。
- 与电脑 2.0.0 使用同一 `E2DayExchange` v1 JSON 文件。保留任务、事件、历史和引用图片；不会导出账号、密码校验值或恢复码。
- 导入预览保留双方独有记录；差异按整条记录选择，确认时先保存本机副本，图片和记录在同一 SQLite 事务内写入。
- 导入的重复事件继续按原规则产生任务；当前手机编辑器只新增普通任务。电脑版保留完整事件编排和历史等功能。
- 不申请互联网权限，不提供自动同步、云账号、RSS、云备份、短信或收费服务。数据库和交换文件未加密；账号用于应用内访问控制，交换文件应自行妥善保存。
- 使用华为官方开发工具和本人开发者调试签名。开发者实名认证、协议确认、账号登录和真机授权由本人完成。调试签名存在有效期和设备范围，以华为控制台实际说明为准；这不是永久商店安装包。

## 开发与构建

需要 PowerShell 7、Node.js 24（测试使用 `node:sqlite`）、本机 .NET 10 SDK 和华为官方工具链。NPM 的 CLI 仅为入口，**不含完整 HarmonyOS SDK**。

项目根目录执行以下命令，依赖只放入忽略的 `.build`：

```powershell
npm install --prefix .build/harmony-cli --cache .build/npm-cache --ignore-scripts --no-audit --no-fund @deveco/deveco-cli@1.3.5
npm install --prefix .build/harmony-tests --cache .build/npm-cache --ignore-scripts --no-audit --no-fund typescript@5.9.3
./scripts/Test-Harmony.ps1 -RefreshFixtures
```

准备好 SDK 后，使用实际安装目录：

```powershell
./scripts/Build-Harmony.ps1 -StudioPath 'C:\Program Files\Huawei\DevEco Studio'
```

也可用 `-CommandLineToolsPath` 指定官方 CLT 安装根。脚本在英文临时目录创建新副本以适配工具链的路径限制，不覆盖已有构建目录；复制范围只包含工程源码和配置，不复制凭据、本地签名或缓存。调用官方 CLI 构建 `entry`，只有找到真实 HAP 后才复制到忽略的 `artifacts/harmony` 并生成 SHA-256。构建不会自动登录、创建个人证书、接受协议、安装或卸载手机应用。

脚本优先使用官方工具包配套的 Node 与 Java，Hvigor 缓存放在英文临时构建根。当前 Windows ARM64 电脑上的 DevEco Studio 26 安装器拒绝安装；本机从本人下载、华为数字签名验证通过的原包中解压 SDK、tools 与运行环境，未修改安装器或编译器，实际命令行构建通过。此结果不表示华为官方已支持 Windows ARM64 IDE 或模拟器，也不要求再下载 Mac / Linux 版本。

HAP 生成后运行以下检查，核验版本、字节码、原生入口、离线资源、权限与 SHA-256：

```powershell
./tests/harmony-package-check.ps1 -PackageDirectory 'artifacts/harmony/实际构建目录'
```

需要用 DevEco Studio 打开时，可打开脚本输出的英文工程目录。签名时在该本地副本中配置本人账号及设备，不把包含口令、密钥路径或证书的配置复制回公开源码。仓库中的 `signingConfigs` 留空。保留自己的签名材料和应用标识，后续更新应使用兼容签名并递增版本，避免卸载丢失数据。

### 为自己的设备签名并安装

使用 DevEco Studio 支持的电脑环境，下载该版本源码并打开原生工程（或脚本输出的英文目录）。按 SDK 随附的“配置调试签名 → 自动签名 → 未关联注册应用”步骤操作：

1. 只连接需要调试的本人手机，开启 USB 调试，在手机上确认电脑授权。
2. 进入 **File → Project Structure → Project → Signing Configs**，选择 **Automatically generate signature**；如未登录，点 **Sign In**，由本人在官方页面完成登录授权，确认配置。
3. 工具会在本机生成密钥、证书和设备 profile。查看有效期及设备范围，妥善备份；这部分本地配置不提交到 GitHub，也不复制回公开源码。
4. 选择自己的手机运行 `entry`，由工具构建签名并安装。已有记录时保留原包名和兼容签名，覆盖安装；首次安装后创建本机账号并保存恢复码。

公开 ZIP 中的 HAP 用于核验构建产物；正常自用流程是在源码工程中生成自己的签名并重新构建运行。无需购买代签、云主机或第三方验证 API。

- 实际 Repository/Crypto 源码配合 Node SQLite/密码适配器验证重开持久化、写图后失败整体回滚、预览过期拒绝、恢复前副本、连续写入、本机账号隔离与恢复码轮换。
- 任务卡片使用稳定身份的可观察模型；完成、撤销、标题、备注与星标更新只替换变化的任务属性，未变化的卡片保留。保存校验图片存在性时不再读取整张图片内容。

调试签名有有效期，也只适用于授权设备。到期前先导出交换文件备份，再用自己的开发者账号更新签名并覆盖安装。保留包名 `com.yilaxin.e2day` 与兼容签名；不要为更新先卸载应用。华为账号的密码和恢复码均不需要发送给项目作者。

## 日常使用与电脑交换

1. 从手机桌面打开 **E²-Day**，创建本机账号并保存恢复码；已登录账号会自动恢复。
2. “今日 → 记一件事”添加标题、日期、重要标记、备注及图片。点任务左侧圆圈标记完成，再点一次撤销；星标切换重要，编辑可改期或取消任务。
3. “日历”按日期查看任务；“账号 → 查看已取消任务”可编辑并恢复取消项。
4. 手机到电脑：手机“账号 → 导出交换文件”，在系统文件选择器保存 JSON，自己传到电脑；电脑“偏好设置 → 手机与文件交换 → 导入交换文件”。
5. 电脑到手机：电脑导出交换文件并传到手机，手机“账号 → 导入交换文件”选择 JSON。先预览，差异按整条记录选择“保留本机”或“采用文件”，再确认合并。
6. 导入前自动保存本机副本；需要回退时用“账号 → 查看导入前副本”。请定期另存交换文件到应用之外；恢复码不能重建已经删除的数据。

## 从当前手机版本迁移

**先保留旧手机桌面图标和站点数据。** 旧网页应用和原生应用各自保存记录，桌面图标可能同名；原生版可在系统应用管理中找到。

原生版安装并验收后，在旧手机应用的“账号 → 文件交换”导出 JSON，存到自己的文件位置；原生版创建本机账号并保存恢复码，在“账号 → 导入交换文件”选择此 JSON，预览后合并。核对任务、图片和完成状态，再从原生版导出一份备份验证电脑可以导入。跨版本账号独立，迁移由交换文件完成。
