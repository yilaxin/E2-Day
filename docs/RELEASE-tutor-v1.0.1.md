# E²-Day 家教版 1.0.1 · 更醒目的添加课程按钮

授课日历中，选中日期后的“在这一天添加课程”改为蓝底白字主按钮，文字加粗、字号增至 16，点击区域增高并增加周围留白，更容易找到和点击。继续为当前所选日期添加课程。

![日期详情添加课程按钮](https://raw.githubusercontent.com/yilaxin/E2-Day/tutor-v1.0.1/docs/images/tutor-calendar-action.png)

提供 Windows ARM64、x64 自包含免安装程序包。完整解压，关闭旧版后运行 E2Day.Tutor.exe，沿用原有家教版本机账号与数据。完整保留旧版本，日常版最新发布入口继续对应 v2.1.0。

家教版核心测试及两个发布程序的 WPF 验证通过，检查程序版本、架构、必要文件与 SHA-256；公开后重新下载程序包进行完整校验。截图来自隔离示例数据。x64 程序在 Windows ARM64 的兼容环境验证。

未做数字签名，许可继续保留版权并允许下载运行正式程序。使用步骤见[家教版说明](https://github.com/yilaxin/E2-Day/blob/tutor-v1.0.1/docs/TUTOR-GUIDE.md)。
