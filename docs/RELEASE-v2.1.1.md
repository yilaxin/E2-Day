# E²-Day 2.1.1 · Windows 玻璃拟态界面

按照粉紫玻璃拟态参考重新设计 Windows 日常版：柔和渐变背景、半透明白色圆角卡片、细白边与轻阴影，配合蓝紫渐变按钮和清晰的深色文字。

- 今日清单、全年总览、放大月历、历史与设置使用一致的玻璃风格；保留全年默认总览及点击月份放大。
- 任务与事件编辑、账号和分享图片同步配色；重要任务继续以金色星标及边框突出，完成任务淡化保留。
- 全年与月历沿用缓存控件；本地账号、数据目录、图文备注、长期任务、提醒、备份与文件交换继续兼容。
- 家教版沿用原有主题与 1.0.3 发布包。鸿蒙原生版维持已发布的 0.1.1，本次不包含尚未发布的 0.2.0 功能。
