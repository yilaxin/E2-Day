# E²-Day Teacher 1.1.0 · 教学概览与可视化

新增侧栏“教学概览”，集中展示授课节奏、学生投入和课后跟进，沿用已有课程与学生档案，无需重复录入。

- **授课热力日历**：按实际时长深浅着色，短范围显示日历格，长范围显示紧凑热力图，点击进入当天课程。
- **课程安排与执行**：堆叠柱形区分已授、取消、过去待确认及今天／未来待上课，按日、周或月汇总，点击缩小到对应时段。
- **学生课时排行**：展示每位学生的授课节数与小时，保留已结课历史，同名学生分开计算；点击打开档案。
- **反馈跟进**：比例图与最早待补列表，点击直接补写；全部待补反馈可按日期与学生进入教学记录。
- **当前学习需求**：在教学生的基础水平、学习节奏、辅导重点与未选择人数，多选分别计数。

支持今天、本周、本月、本年、自选日期及单个学生，单次最多 366 天。实际课时与反馈只统计截至今天的已授课；当前学习标签与日期范围无关，不作为历史成长曲线。取消、改期、重复排课与日历使用相同规则。查看和筛选不修改课程或数据库。
