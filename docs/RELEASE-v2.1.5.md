# E²-Day 2.1.5 · 数据概览连续平滑滚动

数据概览滚轮改为连贯的短过渡，改善连续滚动时一格一格跳动的感觉。

- 连续输入合并到一个滚动目标，按实际经过时间随绘制帧推进，不排队播放多段动画。
- 反向输入立即取消旧方向的剩余距离，停下后迅速收住，不越过上下边界。
- 细小滚轮增量按比例处理，保留 Windows 滚动行数／整页设置；系统关闭客户端区域动画时使用原生直接滚动。
- 点击控件、键盘定位、外部位置变更、页面刷新、窗口尺寸变化、导航或关闭时停止剩余动画；停止后解除帧订阅。
- 平滑滚动仅用于数据概览；保持热力图与收起选择框的整页滚动、展开菜单滚动、统计详情、复制图片与粉紫玻璃风格。滚动不重建图表。
